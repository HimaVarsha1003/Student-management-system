# Student Management System

A simple web application developed using Python Flask to manage student records.

## Features

- View all student records.
- View individual student details.
- Add new student records.
- Edit existing student information.
- Delete student records.

## Technologies Used

- Python
- Flask
- Flask-SQLAlchemy
- SQLite
- HTML
- CSS

## Project Structure

- `app.py` – Main Flask application and application routes.
- `database.db` – SQLite database.
- `base.html` – Base HTML template.
- `index.html` – Displays student records.
- `create.html` – Form to add student details.
- `edit.html` – Form to update student details.
- `student.html` – Displays individual student information.

## Installation and Setup

1. Clone the repository:

   `git clone https://github.com/HimaVarsha1003/Student-management-system.git`

2. Open the project folder:

   `cd Student-management-system`

3. Install dependencies:

   `pip install -r requirements.txt`

4. Run the application:

   `flask run`

5. Open your browser and visit:

   `http://127.0.0.1:5000`
